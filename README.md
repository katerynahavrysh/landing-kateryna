# Лендинг: Катерина Гавриш — фандрейзинг і менеджмент

Односторінковий сайт + форма заявки, яка надсилає заявки вам на пошту.

```
public/index.html        — сам сайт (тексти, ціни, гайди — усе тут)
functions/api/lead.js    — обробник форми (Cloudflare Pages Function)
```

Пошта для заявок береться з налаштувань Cloudflare (`LEAD_TO_EMAIL`).
Пошта для зв’язку на самому сайті — у блоці контактів в `index.html`.

## 1. Resend — сервіс, що надсилає листи (5 хвилин)

1. Зареєструйтеся на https://resend.com **саме з тією поштою, куди мають
   падати заявки** (Kateryna.havrysh@usl.org.ua). Це важливо: на
   безкоштовному тарифі без власного домену листи доходять лише на пошту
   акаунта.
2. API Keys → Create API key (права: Sending access). Скопіюйте ключ
   (`re_...`) — він показується один раз.

Безкоштовно: до 100 листів на день і 3 000 на місяць.

## 2. GitHub

Створіть новий репозиторій і завантажте туди цю папку
(папки `public` і `functions` + README).

## 3. Cloudflare Pages

1. Cloudflare → Workers & Pages → Create → Pages → Connect to Git →
   оберіть репозиторій.
2. Налаштування збірки:
   - Framework preset: **None**
   - Build command: *(порожньо)*
   - Build output directory: **public**
3. Settings → Variables and Secrets додайте:
   - `RESEND_API_KEY` — ключ із Resend (тип **Secret**)
   - `LEAD_TO_EMAIL` — `Kateryna.havrysh@usl.org.ua`
4. Deployments → Retry deployment, щоб змінні підхопились.
5. Надішліть тестову заявку з сайту. **Перевірте папку «Спам»** —
   перші листи з адреси onboarding@resend.dev можуть потрапити туди.
   Позначте лист як «Не спам».

Власний домен для сайту: Pages → Custom domains.

## Згодом (необов'язково): листи від власного домену

Коли з'явиться домен, додайте його в Resend → Domains, пропишіть DNS-записи,
які він покаже, і додайте в Cloudflare змінну
`LEAD_FROM` = `Заявки <site@ваш-домен.ua>`. Листи рідше йтимуть у спам.

## Як редагувати

- **Тексти, ціни** — прямо в `public/index.html`.
- **Гайди** — список `GUIDES` унизу `index.html`. Кнопка «Замовити цей
  гайд» сама підставляє назву в форму.
- **Акція на гайди** — `PROMO_PRICE` і `PROMO_END` унизу `index.html`.
  Після дати плашка акції ховається, а на картках з’являється «Ціна — у заявці».
- **Колір рожевого** — змінна `--pink` на початку стилів.

Кожен push у GitHub автоматично оновлює сайт.
